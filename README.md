# Digital Leaders 2026 — World Map

Interactive map of the Emerging **Digital Leaders 2026 | AI & Tech Careers Edition**
ranking: 276 institutions across 45 countries, explorable by country, hub and
institution.

Built as static files (D3 v7 + TopoJSON, no build step for the app itself) so it
can be served from a CDN and embedded in Webflow.

---

## Running it locally

```bash
python serve.py
# http://localhost:8000/index.html
```

Use `serve.py` rather than `python -m http.server`. The built-in server is
single-threaded — one held-open browser connection blocks every other request
and the server appears to be down — and it sends no `Cache-Control`, so browsers
reuse a stale `index.js` while the HTML updates around it. `serve.py` is
threaded, sends `no-store`, and version-stamps each asset URL with the file's
modification time.

## The data pipeline

The Excel master file is the **single source of truth**. Nothing is ever edited
in `dl-data.json` by hand. It lives one directory above this repository and is
deliberately not committed.

Run these in order after any data change:

```bash
python geocode.py            # OSM Nominatim lookup; --apply writes coordinates
python geocode_aliases.py    # second pass for English exonyms + manual fixes
python audit_hubs.py         # derive hub membership; --apply to write
python build_data.py         # Excel -> data/dl-data.json
python bundle.py             # single-file builds into dist/
```

`build_data.py --check` rebuilds and diffs without writing, so it doubles as a
regression test. `audit_hubs_full.py` prints a per-hub quality report.

### Things that will bite you

- **Geocoding takes ~6 minutes** (Nominatim allows ~1 request/second) and is
  cached in `geocode_cache.json`, so re-runs only fetch what is missing.
- **Institution coordinates in the source workbook were unusable** — only 141
  distinct pairs for 265 institutions, with 33 sitting on Washington DC. That is
  why the geocoding step exists; do not skip it.
- **Hub membership is derived from coordinates**, by a per-hub radius, except
  where a hub is a convention rather than a place. The Golden Triangle is a
  fixed list of seven, because a radius also catches City, The Open University
  and Warwick.
- **A rank beyond the ranking depth is an error, not a tier.** Ranks 1–150 are
  scored; Global also carries a Next 50 at 151–200; anything past 200 is
  reported and treated as unranked.

## How the scoring works

**DL Points** are a comparative score, not a sixth ranking. Each ranking places
150 institutions, and an institution ranked *r* scores `151 − r` — so 1st is
worth 150 and 150th is worth 1. A country's score is the sum over its
institutions.

The **Next 50** (Global ranks 151–200) is a named tier, not extra depth: it is
listed and mapped but scores zero, and it never enters country or hub totals.
Widening the scale to 200 was tested and rejected — it adds 50 points to every
ranked institution, and since DL25 has no Next 50 the entire gain lands in the
Evolution measure as growth that never happened.
